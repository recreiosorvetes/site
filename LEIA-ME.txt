RECREIO DOS SONHOS — PACOTE PARA GITHUB

IMPORTANTE: não envie apenas os arquivos soltos pelo botão Upload files.
O site depende também das pastas _next, brand, comic e game-assets.

Esta pasta já está vinculada ao repositório recreiosorvetes/site.
1. No GitHub Desktop, escolha File > Add local repository.
2. Selecione a pasta recreio-site-github-completo.
3. Clique em Push origin.

O arquivo inicial é index.html.
Mantenha a pasta _next e o arquivo .nojekyll no repositório.
